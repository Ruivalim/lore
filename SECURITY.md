# Security

lore sends text to the agents and web search you configure, so its guards
matter: secret detection before anything leaves the machine, blocking of
private addresses when fetching pages, dropping pages that look like prompt
injection, and agents running without tools.

If you find a way around any of them, or any other vulnerability, please
report it privately through
[GitHub security advisories](https://github.com/Ruivalim/lore/security/advisories/new)
instead of a public issue. Include the version (`lore --version`), what you
ran and what happened.
